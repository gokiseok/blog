# style-guide.md — 글쓰기 톤·스타일 가이드

---

## 1인칭 표기

- **1인칭**: "저" 또는 "오기석"
- **절대 금지**: "고기석"을 1인칭으로 쓰지 말 것 (브랜드명과 혼동)

**예시**:
- ✅ "저(오기석)는 삼성전자를 나와 자영업으로 전환했습니다"
- ✅ "오기석이 직접 만든 도구입니다"
- ❌ "고기석이 직접 만들었습니다" (매장을 운영자로 혼동)

---

## 매장 호칭

- 항상 "**고기석 건대본점**" 풀네임 사용
- 줄여 쓸 경우 "건대본점"
- "고기석" 단독으로 매장을 지칭하는 것 허용 (단, 사람을 지칭하는 맥락과 혼동하지 말 것)

---

## 문장 스타일

**짧고 단호하게.** 수식어 제거.

나쁜 예:
> 사실 자영업을 하다 보면 정말 다양한 어려움이 있는데, 그 중에서도 특히 리뷰 관리는 생각보다 훨씬 시간이 많이 걸리는 작업입니다.

좋은 예:
> 리뷰 관리는 생각보다 시간이 많이 걸립니다. 하루 리뷰 5개면 월 10시간입니다.

---

## 글 구조

```
훅 (3~5줄) → 맥락 (1~2문단) → 본론 (리스트/단계) → 사례 → 결론/CTA
```

- **훅**: 문제 제기, fear-based OK ("매달 10시간을 리뷰 답글에 쓰고 있다면")
- **맥락**: 왜 이 문제가 중요한지 1~2문단
- **본론**: 리스트나 단계별 정리 (H2/H3 사용)
- **사례**: 실제 경험 (고기석 건대본점 또는 실제 데이터 기반)
- **결론**: 핵심 요약 + CTA (다음 글 링크, 도구 링크 등)

---

## 금지 표현

- "~하는 시대입니다" — 진부함
- "사실은", "솔직히 말하면" — 불필요한 전제
- "~라고 할 수 있겠습니다" — 애매함
- "정말", "매우", "굉장히" — 과장 수식어
- "여러분" — 블로그 톤에 안 맞음
- 감성팔이 표현 ("힘든 하루였지만…", "가슴이 뭉클했습니다")
- 이모지 — 절대 금지

- "빨라졌다" → "3분에서 30초로 줄었다"

- 한글 우선, 영어는 괄호 병기
