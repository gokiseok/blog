# keyword-map.md — 카테고리별 키워드 맵

글 작성 시 이 맵을 참조해 키워드를 자연스럽게 배치합니다.  
규칙: 글당 **주 키워드 1개 + 보조 키워드 2~3개** 자연 배치.  
키워드를 억지로 쑤셔넣지 말 것. 문장 흐름이 우선입니다.

## 키워드 배치 원칙

1. **제목**: 주 키워드 1개 반드시 포함
2. **첫 문단**: 주 키워드 자연스럽게 1회 등장
3. **H2/H3**: 주 키워드 또는 질문형 표현 활용
4. **본문**: 주 키워드 전체 3회 이상, 보조 키워드 각 1~2회
5. **description**: 주 키워드 1개 + 보조 키워드 1개 포함 (120자 이내)
6. **tags**: 주 키워드 + 보조 키워드 3~5개
